# YouTube plugin for Player
Search YouTube, preview audio, and save tracks from Player on desktop and Android.

On Android, install the plugin APK and enable **YouTube** in Player. Open Search, select YouTube, and submit a query. In Player 0.3.15 and newer, **Preview** and **Save to library** offer **Include video** and **Save data**, just like sharing a link to Player. Preview starts after the download completes; Save to library imports the downloaded file.

To save audio or video with sound from a link, share it from YouTube or YouTube Music to **Player** and choose the format and data-saving option.
